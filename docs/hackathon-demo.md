# 3–5 minute demo

Build and run npm run dev. Use synthetic information only. Start npm run api if demonstrating the optional AI check.

1. Open Ask privately and select **Try a shopping example**. Explain the task. Show the two laptop specifications/prices included and the name, email, delivery, cart and credential blocks excluded.
2. Toggle a public fact and show that approval clears. Remove a detail from the preview. Approve, choose Open Gemini (or another destination) and show that only the reviewed packet is copied; the blank chat receives no original tab or automatic submission.
3. On a test webpage with product sections, demonstrate the outline picker, Add a section and a partial text highlight. Show an empty selection producing a message instead of collecting the whole page. Change the source webpage and show the captured packet stays frozen.
4. Optionally consent to the reduced-draft AI check. It can remove blocks but cannot rewrite facts; approval clears. Groq is infrastructure, not the user's chatbot.
5. Demonstrate Present safely with the synthetic customer page and WhatsApp fixture. Show category controls outside the shared page, Blur/Hide, repeated manual selection, undo and restoration. Show the clean meeting snapshot and explain desktop limitations.
6. If time permits, show screenshot OCR, manual rectangles and opaque PNG export.

Do not demonstrate obsolete payment/threat tools or claim universal interception, desktop filtering, anonymity or zero leakage. Evidence is in docs/screenshots and the test report.

For the 0.6.0 upgrade, use a synthetic label/value application table to demonstrate names, DOB, income and identifying photos covered while labels/public specifications remain readable. Show exact element/rectangle capture for Ask privately. Enable reminders on a browser capture test site, reload, cancel a capture, then continue with a prepared tab. Explain that reminders are optional per-site and cannot detect native recorders or enforce desktop protection. The labels-only AI check must show its exact list and consent before a request.
