# Design decisions

User instructions supersede the PRD's blue palette. The implementation uses warm neutral surfaces, a charcoal-green navigation rail, restrained forest-green actions, amber uncertainty labels and solid ink redaction. There are no fake security scores, live dashboards, threat-count animations, robot imagery or neon effects.

Research references: [CrowdStrike platform](https://www.crowdstrike.com/en-us/platform/) and [SentinelOne](https://www.sentinelone.com/), reviewed 2026-09-22. Their product-focused hierarchy and explicit security capability grouping informed the navigation and content organization. The final palette is an independent design choice, not a copy or claim of affiliation.

One tool occupies the workspace at a time. Ask privately follows task → scoped capture → block review → exact approval → handoff. Included/excluded blocks explain the disclosure boundary; the optional processor appears under consent rather than as a product brand. Narrow widths use compact text navigation and stacked panels. Product headings stay beside the specifications they identify. No remote fonts. Automated WCAG A/AA checks report zero violations on the initial dashboard; this is not a full accessibility certification.
